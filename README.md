# 🚀 برتفوليو عبد السلام (Abdel Salam) | AM Marketing

> **نسخة طبق الأصل (Twin Clone)** في التصميم، الأنيميشن، المكونات، وتجربة المستخدم من برتفوليو `kerolesadel.vercel.app` مع دمج الهوية الحقيقية لعبد السلام، مشاريعه، خدماته، وأرقامه.

---

## 🌟 الميزات والمكونات المدمجة

1. **تصميم عصري بالكامل (Dark Glassmorphism)**:
   - خلفية تدرجية داكنة مع كرات إضاءة متوهجة ناعمة (`blur-3xl`) وشبكة خطوط تقنية.
   - تأثيرات الزجاج الشفاف (`backdrop-blur-md` و `card-base`).
2. **دعم ثنائي اللغة سلس (عربي 🇸🇦 / English 🇬🇧)**:
   - زر تبديل اللغة الفوري في النافبار يحول اتجاه الصفحة (`rtl` / `ltr`) والخطوط (`Cairo` للعربية و `Inter` للإنجليزية) فوراً بدون إعادة تحميل.
3. **قسم البداية (Hero Section)**:
   - شارة ترحيبية بتأثير يدوي لامع.
   - العنوان التعريفي باسم عبد السلام ومجاله.
   - إطار نصف دائري مميز مع صورتك الحقيقية.
   - أزرار سريعة (`المشاريع ↗` و `وظّفني / استشارة`).
4. **نبذة عني (About Me)**:
   - نصوص تعريفية برؤية عبد السلام في الجمع بين تطوير الويب والتسويق الرقمي المربح.
   - بطاقات إحصائيات سريعة (+25 مشروع، +15 حملة إعلانية، +20 تقنية).
   - بطاقة تعريفية ذكية (الموقع، الحالة، التخصص، سرعة الرد).
   - خطوات منهجية العمل الثلاثية (01 التخطيط والاستراتيجية، 02 التطوير الحديث، 03 التحسين والنمو).
5. **المهارات التقنية (Technical Skills)**:
   - أزرار تصفية تفاعلية مقسمة حسب التخصص:
     - 💻 **تطوير الويب والبرمجة (BUILD)**: React, Next.js, TypeScript, Tailwind, Redux, APIs.
     - 📈 **التسويق وإعلانات جوجل (GROW)**: Search Ads, Call Ads, Maps, Lead Gen, SEO, CRO.
     - 🎬 **استوديو الـ AI والمونتاج (AI STUDIO)**: Runway Gen-3, Midjourney, 4K Reels, Delogo.
     - 🛡️ **الأمن السيبراني والبنية (PROTECT)**: Cloudflare WAF, PenTesting, Hardening, Git, VPS.
   - بطاقات المبادئ الأربعة (تعلّم سريع، معايير الجودة، التطوير المستمر، التركيز على عائد الاستثمار).
6. **معرض الأعمال (Featured Projects) مع نافذة معاينة ذكية (Lightbox Modal)**:
   - تصفية المشاريع حسب المجال.
   - بطاقات بمؤثرات تكبير عند التمرير وشارات للميزات الرئيسية.
   - نافذة منبثقة (Modal) عند النقر على أي مشروع لعرض: التحدي، الحل المنفذ، الأرقام والنتائج المحققة، ورابط المعاينة المباشر.
7. **مساري وخبراتي (Experience & Journey)**:
   - خط زمني تفاعلي بعقد مضيئة لمحطات عملك وتأسيسك لوكالة AM Marketing وإشرافك على مبادرة "بَلِّغُوا عَنِّي وَلَوْ آيَة".
   - مسار الشهادات والتعليم والتعلم المستمر.
8. **تواصل معي (Contact & Fast Quote)**:
   - بطاقات قنوات الاتصال المباشرة: الهاتف والواتساب (`01098174992`)، البريد، صفحة الفيسبوك، وGitHub.
   - نموذج تفاعلي ذكي يقوم بتهيئة رسالة واتساب منسقة بكامل تفاصيل العميل والخدمة المطلوبة ويفتح محادثة واتساب معك بضغطة زر واحدة!
9. **زر واتساب عائم (Floating WhatsApp)**:
   - زر عائم مع هالة نبض مضيئة في الزاوية للوصول السريع من أي مكان في الموقع.

## 💻 طريقة التشغيل والمعاينة المحلية

المشروع متواجد بالكامل في القرص:
```
D:\portfolio
```

### الطريقة السريعة (بدون كتابة أوامر):
- اضغط مرتين (Double Click) على الملف:
  ```
  D:\portfolio\تشغيل_البرتفوليو.bat
  ```
  سيقوم السيرفر بالتشغيل وفتح متصفحك تلقائياً على الرابط:
  `http://localhost:3000`

### من خلال الطرفية (Terminal / PowerShell):
```powershell
cd D:\portfolio
npm run dev
```

## 📦 بناء المشروع للرفع والنشر (Deployment)

إذا أردت رفع المشروع إلى استضافة مثل **Vercel** أو **Netlify** أو **GitHub Pages**:
- اضغط مرتين على:
  ```
  D:\portfolio\بناء_للنشر.bat
  ```
  أو اكتب في الطرفية:
  ```powershell
  npm run build
  ```
  وسيتم توليد الملفات الجاهزة للنشر الفوري داخل المجلد `D:\portfolio\dist`.
