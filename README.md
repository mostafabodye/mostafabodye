# 🚀 منصة ووكالة AM Marketing | عبد السلام
### (GROW • BUILD • PROTECT • AI STUDIO)

منصة رقمية ووكالة تسويق متكاملة متعددة الصفحات (Multi-Page Digital Agency Web Platform) مصممة ومبنية خصيصاً للمؤسس **عبد السلام (AM Marketing)** لتقديم خدمات إعلانات جوجل الاحترافية، وتطوير المواقع والمتاجر، وحلول الذكاء الاصطناعي والمونتاج، والأمن السيبراني.

---

## 🌟 الهيكل العام للمنصة (Multi-Page Architecture)

| الصفحة | المسار | الوظيفة والمحتوى |
|---|---|---|
| **الرئيسية (Home)** | `index.html` | البوابة الشاملة، أداة فحص الـ AI التفاعلية، حاسبة الـ ROI، مركز المعرفة للمقالات، ملخص الخدمات |
| **إعلانات جوجل والتسويق (GROW)** | `services-marketing.html` | حملات Google Ads الحقيقية (المجال للسلامة + شبكة الأوناش) وبطاقات المقالات الاستراتيجية |
| **تطوير المواقع والمتاجر (BUILD)** | `services-web.html` | باقات تطوير المواقع السريعة، المواصفات التقنية، وباقة البداية الاقتصادية (250 SAR) |
| **استوديو الذكاء الاصطناعي (AI STUDIO)** | `services-creative-ai.html` | مشغلات فيديو حية (سلسلة حواديت 4K + مقاطع القرآن) وقسم الهوية البصرية 3D لصفحة بلغوا عني ولو آية |
| **الأمن السيبراني وحماية الويب (PROTECT)** | `services-security.html` | فحص الثغرات الأمنية، جدران الحماية السحابية WAF، وتأمين المنصات |
| **معرض الأعمال ودراسات الحالة (Portfolio)** | `portfolio.html` | سابقة أعمال تفاعلية (9 مشاريع موثقة) مع الفلاتر ونوافذ النتائج بالأرقام |
| **عن الوكالة والمؤسس (About)** | `about.html` | قصة المؤسس عبد السلام، رؤية الوكالة، وبطاقة مبادرة "بَلِّغُوا عَنِّي ولو آية" الرسمية |
| **تواصل معنا وطلب عرض سعر (Contact)** | `contact.html` | نموذج اتصال ذكي يرسل البيانات مهيكلة مباشرة إلى رقم واتساب `01098174992` |
| **دليل مستقبل إعلانات جوجل (Article 1)** | `blog-google-ads-future.html` | مقال استراتيجي معتمد حول الذكاء الاصطناعي، Performance Max، والتحول إلى مستشار أعمال |
| **دليل قسيمة إعلانات جوجل (Article 2)** | `blog-google-ads-coupon.html` | دليل تطبيقي لكيفية الحصول على رصيد ترويجي مجاني (100$ - 500$) واستثماره بأعلى عائد |
